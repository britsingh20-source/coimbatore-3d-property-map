# Coimbatore 3D Property Map

Full-screen interactive 3D property map centred on Vadavalli, Coimbatore.

## Add or update properties

Published property records have two location layers. Customers receive only a general area label and an approximate pin around 1 km away. Exact coordinates stay server-side and are returned only to authenticated staff; owner, manager and builder contacts remain Director-only. Each property can also store an Instagram Reel link for in-panel playback and privacy-safe WhatsApp sharing.

## Development

```bash
npm install
npm run dev
```

Every push to `main` automatically deploys through GitHub Pages.
