# Coimbatore 3D Property Map

Full-screen interactive 3D property map centred on Vadavalli, Coimbatore.

## Add or update properties

Edit `src/properties.js`. Each property contains the exact longitude and latitude used for its budget marker. Confirm the pin visually before publishing.

## Development

```bash
npm install
npm run dev
```

Every push to `main` automatically deploys through GitHub Pages.
